# JLCCNC sheet-metal quote page (read 2026-11-04 from the JLCONE app; nothing uploaded, saved or submitted)

`jlccnc.com/sheet-metal-quote`. The page takes a file first (STEP, STP, DWG, DXF, PDF, Zip, Rar, under 100 MB) and its terms forbid weapons and export-controlled parts. Without a file it offers "Explore the Demo" (`sheet_metal_sample.step`, 21 x 11 x 10 mm, volume 305.71 mm3, Aluminum 5052, no finish), and its Edit Specifications panel shows the options:

| Field | Options |
|---|---|
| Material | Aluminum, Stainless Steel, Steel Alloy |
| Type of Aluminum | a list (the demo shows 5052, temper O, with its properties: tensile 170-305 MPa, yield over 90 MPa, modulus 69.3-70.7 GPa) |
| Surface Finish | No, Yes (a finishes list) |
| Threads and Tapped Holes | No, Yes |
| Qty, Product Desc, Remark | free fields |

The demo quoted C$3.76 (the page showed $2.70 before the account currency loaded). A real part is **quoted manually in 2 to 4 hours (Mon-Sat 9am-6pm, GMT+8)**, build time Standard 2 days (the charge changes with the build time). The default shipping line is UPS Worldwide Express Saver (C$37.41); the account's coupons shown on this page: Save C$69.64 and Save C$55.71. The real arm quote needs an uploaded file (`hardware/balance/boards/fab/arm_cnc.dxf` exists); upload only when the user decides to quote the aluminium arm (shelved).
